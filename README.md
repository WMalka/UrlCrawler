# Job-Based Web Crawler

Event-driven crawler: **Crawl API** (ASP.NET Core 8) → **RabbitMQ** (MassTransit) → **Crawl Worker** (.NET 8) → **SQL Server**, with a **React** UI.

> Work in progress. See [docs/CURRENT_STATUS.md](docs/CURRENT_STATUS.md) and [docs/DECISIONS.md](docs/DECISIONS.md).
